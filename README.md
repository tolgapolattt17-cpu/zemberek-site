# Zemberek Web

Zemberek iOS uygulamasının resmi web sitesi.

- https://zemberek.app — Ana sayfa
- https://zemberek.app/privacy-policy.html — Gizlilik Politikası
- https://zemberek.app/terms-of-service.html — Kullanım Koşulları

Destek: destek@zemberek.app
- https://zemberek.app/community-rules.html — Topluluk Kuralları
- https://zemberek.app/kvkk-aydinlatma.html — KVKK Aydınlatma Metni
- İngilizce sürümler: `*-en.html`

> Yasal sayfalar (gizlilik, koşullar, topluluk kuralları, KVKK) uygulama reposundaki `scripts/legal_content.py` kaynağından
> `python3 scripts/generate_legal.py` ile üretilir; bu dosyaları elle düzenlemeyin (uygulama içi metinle aynı kalması için).
